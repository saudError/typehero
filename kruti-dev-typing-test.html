Kruti Dev Typing Test - Kruti Dev 010 Hindi Typing Practice

Kruti Dev 010 हिंदी टाइपिंग का सबसे जाना-माना layout है, जो सरकारी दफ़्तरों और कई भर्ती परीक्षाओं में पूछा जाता है। यहाँ आप उसी layout में online typing test दे सकते हैं, वह भी बिना कोई font install किए।

Kruti Dev 010 क्या है?

Kruti Dev 010 एक Hindi font और उससे जुड़ा keyboard layout है। यह typewriter जैसी तर्ज़ पर चलता है, जिसमें मात्राएँ अक्षर से पहले टाइप की जाती हैं और आधे अक्षर की अपनी key होती है।

पुराने typewriter से आए लोगों को यह layout सहज लगता है, इसलिए यह सरकारी कामकाज में अब भी बहुत चलता है।

Chiku Type पर Kruti Dev कैसे इस्तेमाल करें

  1. ऊपर के बटन से Kruti Dev test खोलें, या typing test पेज पर language list में Kruti Dev 010 चुनें।
  2. अपना कंप्यूटर English कीबोर्ड पर ही रखें। हर key दबाने पर सीधे Hindi अक्षर बनेगा।
  3. ऑन-स्क्रीन keyboard चालू करके देखें कि कौन-सी key पर कौन-सा अक्षर है।
  4. Lessons में step-by-step अभ्यास करें और फिर timed test दें।

Kruti Dev में speed बढ़ाने के टिप्स

  • पहले मात्राओं की key याद करें, क्योंकि Kruti Dev में ग़लती इन्हीं पर ज़्यादा होती है।
  • आधे अक्षर और संयुक्त अक्षर वाले शब्दों का अलग से रोज़ अभ्यास करें।
  • छोटे test (1 मिनट) से शुरू करके धीरे-धीरे 10 मिनट तक जाएँ।
  • अपना रोज़ का WPM किसी कॉपी में लिखकर प्रगति देखें।

दूसरे layout से तुलना

Remington Gail की तैयारी के लिए Remington Gail typing test और Unicode (InScript) अभ्यास के लिए Hindi typing practice देखें। SSC के लिए SSC typing practice पेज बना है।

अभ्यास के लिए नमूना अनुच्छेद

सरकारी कार्यालयों में हिंदी टाइपिंग का महत्त्व आज भी बना हुआ है। सही मात्रा और शुद्ध वर्तनी के साथ टाइप करना एक अच्छे टाइपिस्ट की पहचान है।

अक्सर पूछे जाने वाले सवाल

क्या Kruti Dev typing test free है?

हाँ, Chiku Type पर Kruti Dev layout में typing practice free है।

क्या Kruti Dev font install करना ज़रूरी है?

नहीं। आप English कीबोर्ड से ही टाइप करते हैं और Chiku Type हर key को सीधे Kruti Dev layout के हिसाब से बदलता है।

Kruti Dev और Mangal में क्या फ़र्क है?

Kruti Dev typewriter शैली का font-आधारित layout है, जबकि Mangal (InScript) Windows का standard Unicode layout है। दोनों में key की जगहें अलग होती हैं।

क्या SSC के लिए Kruti Dev चलेगा?

SSC के notification में आम तौर पर Kruti Dev 010 या Mangal का ज़िक्र होता है। अपने साल का आधिकारिक notification देखकर layout पक्का करें।
